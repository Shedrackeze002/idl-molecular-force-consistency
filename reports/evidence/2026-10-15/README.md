# Results and evidence through 15 October 2026

This export retains successful, unsuccessful, invalid and interrupted outcomes. Original source-bound journals, full checkpoints, raw labels, review packages and large runtime traces are retained separately. This directory is a compact numerical evidence export, not a claim that every original package is available from a clone.

- [MACE Run A report](mace-runA/report.json): final EMA epoch 2047 primary and weighted-loss-selected epoch 1987 secondary, four byte-identical prediction arrays and both strict CPU/log check receipts. Both independent result reviews approve the one-seed, same-split working-reference reading. No test/relaxation or causal data-size conclusion.
- [Energy engineering fit](e3x/energy/summary.json) and [direct fit](e3x/direct/summary.json): each 1,000 updates/max_updates, BEST at update 0/LAST at update 1000, finite checkpoint/reload controls. Both validation-force outcomes are worse than zero-force initialization. Energy MAE improves. These engineering fits consume no scientific candidate slots.
- E3x full loss/validation histories, source/provenance/config identities and both checkpoint reference arrays/receipts are retained per arm. Independent arithmetic checks group reductions and objective decompositions, not a new full-array validation rescore.
- [Force-isolation result](prior-diagnostics/force-isolation-diagnostics.json): completed, both learning gates fail. [Angular-degree result](prior-diagnostics/angular-degree-diagnostics.json): execution-invalid/incomplete, no scientific gate verdict. Earlier diagnostics remain linked in the shared evidence index.
- [Attempt index](attempt-index.md) preserves operating failures, incomplete runs and unresolved limitations.
- [Export manifest](export-manifest.json) gives original and published SHA-256 values and every structured location-field transformation. Numerical values, record IDs, roles and arrays are preserved.
